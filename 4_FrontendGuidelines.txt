4. Component Design Specifications
4.1 Navbar
Height: 64px (desktop) / 56px (mobile)
Background: White with bottom shadow
Left: Store Logo + Name (Playfair Display, saffron)
Center: Navigation links (Home, Shop, Collections, About, Contact)
Right: Search icon, Wishlist icon, Cart icon (with badge), User avatar / Login
Sticky on scroll
Mobile: Hamburger menu with slide-in drawer
// Example Navbar structure<nav className="sticky top-0 z-50 bg-white shadow-sm h-16 flex items-center justify-between px-6">  <Logo />  <NavLinks className="hidden md:flex" />  <NavActions /> {/* Search, Wishlist, Cart, User */}  <HamburgerMenu className="md:hidden" /></nav>
4.2 Product Card
Width: 100% of grid column
Aspect Ratio: Image 1:1 square
Corner radius: 12px
Shadow: shadow-md hover:shadow-xl transition
Hover: Slight translateY(-4px) scale
Sale Badge: Top-left, saffron background, white text, “X% Off”
Price: Strikethrough original, bold saffron for sale price
“Add to Cart” button: Full width, saffron fill, appears on hover (desktop) / always visible (mobile)
<div className="rounded-xl overflow-hidden shadow-md hover:shadow-xl transition-all hover:-translate-y-1 cursor-pointer bg-white">  <div className="relative">    <img src={product.image} className="w-full aspect-square object-cover" />    {product.discount && (      <span className="absolute top-2 left-2 bg-saffron-500 text-white text-xs font-bold px-2 py-1 rounded-full">        {product.discount}% Off      </span>    )}  </div>  <div className="p-3">    <h3 className="font-semibold text-puja-text text-sm line-clamp-2">{product.name}</h3>    <div className="flex items-center gap-2 mt-1">      <span className="text-saffron-500 font-bold">₹{product.salePrice}</span>      <span className="text-puja-muted line-through text-sm">₹{product.originalPrice}</span>    </div>    <button className="mt-2 w-full bg-saffron-500 hover:bg-saffron-600 text-white py-1.5 rounded-lg text-sm font-semibold transition">      Add to Cart    </button>  </div></div>

10. Accessibility Requirements
All images must have alt text
Buttons and links must have visible focus states
Color contrast ratio: minimum 4.5:1 (WCAG AA)
Forms must have label associations
Interactive elements minimum 44x44px touch target
Skip-to-content link at top of page
