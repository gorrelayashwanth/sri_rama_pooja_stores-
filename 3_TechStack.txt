1. Overview
This document defines the complete technology stack for the Sri Rama Pooja Store e-commerce platform. The stack is selected to support rapid development in Antigravity (Claude Sonnet 4.6), real-time admin control, and scalable production deployment.

9. API Architecture

JWT Bearer token authentication
JSON request/response format
Standardized error response format:
{  "success": false,  "message": "Unauthorized",  "error": "TOKEN_EXPIRED"}
Standardized success response:
{  "success": true,  "data": {},  "message": "Product created successfully"}
